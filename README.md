### 📝 Hub Diário com IA
Um organizador pessoal com gestão de tarefas, lista de compras e anotações, potenciado pela **API Gemini da Google**.  

- **Tecnologias:** HTML, Tailwind CSS, JavaScript  
- **Repositório:** [GitHub](https://github.com/DayanaNogueira/lista-de-tarefas)  
- **Demo:** [Ver ao vivo](https://dayananogueira.github.io/lista-de-tarefas/)

### 🎬 CineInfo: Explorador de Filmes
Aplicação web responsiva para **buscar, explorar e favoritar filmes**, com **modo claro/escuro** e **animações modernas**, consumindo a API do TMDb.  

- **Tecnologias:** React, Framer Motion, CSS, API  
- **Repositório:** [GitHub](https://github.com/DayanaNogueira/cineinfo)  
- **Demo:** [Ver ao vivo](https://dayananogueira.github.io/cineinfo/)
